# Presentation sources

The 12-slide English deck covers the problem, roles, contract flow, real local demonstration, architecture, security, testing and public deployment.

- `NOTES.en.md`: narration and technical notes for each slide.
- `deployment.json`: final repository, deployment and verification facts.
- `assets/` and `ASSETS.json`: screenshots from the recorded local demonstration and source-frame references.

Editable PowerPoint and PDF files are supplied in the course submission package. Member names and student IDs are added to private submission materials after confirmation.
