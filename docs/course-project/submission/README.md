# Course submission reading materials

These English reading copies explain the implemented application and the evidence behind its submitted demonstration.

- `REPORT_SOURCE.md`: complete 15-page technical report content, including the problem, requirements, five design views, security, tests, impact and public release.
- `USER_MANUAL_SOURCE.md`: role-based instructions for the recorded local workflow, with public-access details and troubleshooting.
- `DEPLOYMENT_TESTING_SOURCE.md`: verified cloud endpoints, Sepolia contracts, receipts and continuous integration.
- `CONTRIBUTION_SOURCE.md`: traceable work packages and reuse provenance; individual attribution requires the students' confirmed account.
- `SUBMISSION_FACTS.json`: public release facts and reference URLs.
- `DOCUMENT_VALIDATION.json`: document page counts and integrity records.
- `assets/diagrams/`: architecture, contract interaction, lifecycle, data model and interface diagrams.
- `assets/screenshots/`: two actual stills from the tournament 13 recording.

The Markdown copies use generic group metadata. Names, student IDs and confirmed personal contributions belong in the private submission documents. Editable DOCX and PDF deliverables are distributed separately; rendering intermediates and local document-building utilities are not part of this public reading directory.

The recorded financial workflow and real-model match run locally. The public Render instance uses deterministic simulation; its verified scope is HTTPS access, API readiness, chain configuration and wallet connection entry. See the deployment record for the precise acceptance boundary.
